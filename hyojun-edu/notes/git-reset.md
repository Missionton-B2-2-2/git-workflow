# Git reset 학습 노트

## 작성자

- hyojun-edu

## 학습 목적

git reset 커맨드의 hard, soft 옵션을 이해하고 적절하게 활용한다.

## 핵심 개념

- `git reset`: 스테이징된 변경사항을 unstaged 상태로 되롤린다.
- `git reset --hard`: 커밋되지 않은 변경사항을 삭제한다.
- `git reset --hard HEAD~1`: 커밋을 취소하면서 변경사항을 삭제한다.
- `git reset --soft HEAD~1`: 커밋을 취소하면서 변경사항을 유지한다.

## 실습 과정

1. 임시로 커밋을 하나 생성했다.
2. `git reset --soft HEAD~1` 커맨드로 변경 내용을 유지하면서 커밋을 취소했다.
3. `git reset` 커맨드로 스테이징된 변경 사항들이 unstaged로 바뀌는 것을 확인했다.
4. `git reset --hard` 커맨드로 로컬 변경 사항들이 삭제되는 것을 확인했다.
5. `git reset --hard HEAD~1` 커맨드로 마지막 커밋이 삭제되고 이전 커밋 상태로 복구되는 것을 확인했다.

## 실습 결과
git reset 커맨드의 여러가지 옵션을 사용해서 다양한 기능을 수행할 수 있음을 배울 수 있었다.

## 사용하면 좋은 상황

- 로컬의 변경사항을 삭제하고 마지막 커밋 내용으로 복구하고 싶을 때
- 커밋을 취소하고 그 이전 내용으로 복구하고 싶을 때
- 커밋을 취소하지만 변경사항은 유지하고 내용을 추가해서 다시 커밋하고 싶을 때 

## 주의점

reset hard 옵션으로 삭제된 내용은 복구하기 어렵기 때문에 조심해서 사용해야 한다.
