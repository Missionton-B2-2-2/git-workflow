## Gitflow 선택 이유
- 명확한 브랜치 역할 분리: 각 브랜치의 목적이 뚜렷해 개발자 간의 혼란과 코드 충돌을 줄입니다.
- 대규모 및 분산 팀 협업 적합성: 병렬적으로 이슈를 할당해 작업하면서도 main 브렌치는 항상 깨끗한 상태로 유지할 수 있습니다.
- 체계적인 버전 및 릴리스 관리: main 브렌치가 항상 안정 버전이기 때문에 필요에 따라 버전을 생성하여 릴리즈를 관리하기에 용이합니다.
